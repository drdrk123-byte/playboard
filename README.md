# ♟️ 우리반 보드게임 — 오목·바둑·체스·장기

학생들이 각자 태블릿·크롬북으로 접속해 실시간으로 대국하는 웹앱입니다.
빌드 과정 없는 단일 `index.html` + Firebase Firestore(실시간 동기화).

## 공통 기능
- 반·번호·닉네임만 입력하고 입장 (개인정보 최소화, 로그인 없음)
- 로비: 방 만들기 / 참가 / 관전, 실시간 방 목록 (6시간 동안 움직임 없는 방은 숨김)
- 기권, 자리 바꿔 다시 하기, 방 없애기
- 두 번 눌러 착수(실수 방지) 옵션, 마지막 수 표시, 내 차례 진동 알림
- Firebase 없이도 되는 "한 기기에서 둘이 하기" 모드

## 게임별 규칙
| 게임 | 지원하는 규칙 |
|---|---|
| 오목 | 15×15, 자유 오목(5목 이상 승리), 승리 줄 표시 |
| 바둑 | 9·13·19줄, 따내기, 자충수 금지, 패, 패스 2번 → 자동 계가(덤 6.5) |
| 체스 | 캐슬링, 앙파상, 승급 선택, 체크·체크메이트, 무승부(스테일메이트, 50수, 3회 반복, 기물 부족) |
| 장기 | 마·상 차림 선택, 궁성 대각선, 포·마·상 길 막힘, 장군·외통수, 빅장(무승부), 한 수 쉬기, 점수 계산(한 덤 1.5) |

## 체스·장기 학습 도움
- 말을 누르면 **이름표**, **움직이는 법**, **갈 수 있는 칸**(초록 점: 이동, 빨간 테두리: 잡기)이 보입니다.
- 상대 말이나 내 차례가 아닐 때도 눌러서 확인할 수 있습니다(관전자 포함).
- 체스판은 말 이름을 항상 표시합니다(체크박스로 끌 수 있음). 장기 말에는 한글 이름이 적혀 있습니다.
- 왕이 위험해지는 수는 갈 수 있는 칸에 표시되지 않습니다.
- 온라인 체스·장기에서는 나중에 두는 쪽의 판이 돌아가 자기 말이 아래에 보입니다.

## 간단하게 처리한 부분
- 바둑: 죽은 돌은 자동 판정하지 않습니다. 계가는 중국식(돌 + 집)입니다.
- 장기: 반복수 규칙은 판정하지 않습니다. 같은 수가 계속되면 두 사람이 모두 쉬어 점수로 정하세요.
- 장기: 차림은 첫 수 전에 각자 바꿉니다(한이 먼저 정하는 순서는 강제하지 않음).
- 시간 제한(초읽기)과 무르기는 없습니다.

## 설정
> **현재 상태:** `index.html`은 Firebase 프로젝트 `lifegame-eea21`의 `playboard` 웹 앱에 연결되어 있습니다.
> 이 프로젝트는 다른 앱(인생게임 등)과 함께 씁니다. `firestore.rules`가 게시되어 있어 **Firestore는 `gameRooms`만 열려 있습니다.**
> ⚠️ 이 프로젝트의 다른 앱에서 Firestore를 새로 쓰려면, 그 컬렉션의 규칙을 `firestore.rules`에 추가해야 합니다. (Realtime Database 규칙은 별개입니다)

아래는 새 프로젝트에 처음 설정할 때의 순서입니다.

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트 선택(기존 프로젝트 재사용 가능) → **Firestore Database** 만들기
2. Firestore **규칙** 탭에 `firestore.rules` 내용을 붙여넣고 게시
   (다른 앱의 Firestore 규칙이 있으면 `gameRooms` 블록과 그 아래 함수들만 추가하거나 교체)
3. 프로젝트 설정 → 웹 앱 → `firebaseConfig` 값을 `index.html`의 `firebaseConfig`에 붙여넣기
4. GitHub에 푸시 → Vercel에서 Import (Framework Preset: **Other**, Build 명령 없음)

## 참고
- 로비는 `createdAt` 내림차순 정렬만 사용하므로 별도 색인이 필요 없습니다.
- 수가 규칙에 맞는지는 각 기기(브라우저)에서 검사합니다.
- Firestore 규칙은 저장 항목·길이, 자리 변경(참가·다시 하기), 끝난 대국 수정 금지를 검사합니다. 수의 옳고 그름이나 보낸 사람이 누구인지는 검사하지 못합니다. 로그인이 없어 누구나 방을 읽고 지울 수 있고, 진행 중인 판을 조작할 수도 있습니다.
